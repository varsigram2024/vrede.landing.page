# vrede-landing-page

Vite and React project generated by Figma to Code.

## Requirements

- Node.js >=24
- npm

## Run the project

```sh
npm install
npm run dev
```

Open the URL printed by Vite. The generated UI is in `src/App.tsx`, Tailwind CSS is loaded from `src/index.css`, and exported images are in `public/images/`.

## Validate a production build

```sh
npm run typecheck
npm run build
npm run preview
```

## Before shipping

Review component boundaries, responsive behavior, accessibility, state management, data loading, and interactions. This export is intentionally dependency-light and does not invent application logic.
